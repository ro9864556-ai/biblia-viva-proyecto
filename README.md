# Biblia Viva

Herramienta gratuita para explorar, estudiar y enseñar la Palabra de Dios.

## Contenido

- Lector bíblico con la Versión Biblia Libre (VBL).
- Atlas bíblico didáctico, con acontecimientos vinculados a lugares.
- Ilustraciones de versículos, identificadas como recreaciones artísticas.
- Lectura con notas y favoritos guardados en tu equipo.

## Ejecutar en desarrollo

Requisitos: Node.js 20 o superior y Windows 10/11.

```bash
npm install
npm start
```

Para generar el instalador: `npm run dist`.
